# 🚀 Portfólio Pessoal – Plataforma Viva de Demonstração Técnica

Bem-vindo ao meu portfólio pessoal!
Este projeto funciona como uma **plataforma viva de demonstração técnica**, onde reúno diferentes projetos de prova de conceito (**PoCs**) com foco principal em **Backend Engineering**, arquitetura de software e práticas modernas de infraestrutura.

🌐 **Acesse aqui:** [valerianofc.codes](https://valerianofc.codes/)

---

## 📌 Sobre o Projeto

Este repositório não é apenas um portfólio tradicional — é um verdadeiro **laboratório prático de engenharia de software**, onde desenvolvo, testo e publico soluções reais com foco em:

- APIs RESTful
- Microserviços
- Sistemas de mensageria
- Autenticação e autorização
- Integrações entre serviços
- Padrões de projeto
- Infraestrutura e automação de deploy

Cada projeto representa uma **PoC (Proof of Concept)** criada para validar arquiteturas, tecnologias e boas práticas aplicadas ao desenvolvimento backend moderno.

---

## 🛠️ Tecnologias e Ferramentas

### Backend & Arquitetura

- Clean Architecture
- Domain-Driven Design (DDD)
- SOLID Principles
- Design Patterns
- Testes automatizados
- APIs REST
- Microservices
- Event-Driven Architecture

### Infraestrutura & DevOps

- Docker
- Docker Compose
- Nginx
- GitHub Actions (CI/CD)
- Deploy automatizado
- Gestão de subdomínios
- Monitorização básica
- Orquestração leve de serviços

### Performance & Escalabilidade

- Apache Kafka (mensageria)
- Redis (caching)
- Processamento assíncrono
- Filas e eventos distribuídos

### Frontend

- Interface mínima para exposição das demonstrações
- Visualização e navegação entre PoCs publicadas
